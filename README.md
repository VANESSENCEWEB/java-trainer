## ▶️ Como executar cada programa

Entre na pasta do exercício, compile e execute:

```bash
cd 01-calculadora-simples
javac Calculadora.java
java Calculadora
```

Troque o nome da pasta e do arquivo conforme o exercício que quiser rodar.
